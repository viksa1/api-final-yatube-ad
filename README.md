# API Yatube

API для социальной платформы Yatube, разработанный на Django REST Framework.

## Возможности

- Получение списка публикаций и просмотр отдельных публикаций.
- Создание, редактирование и удаление публикаций.
- Работа с комментариями.
- Просмотр групп.
- Подписка на других пользователей.
- Авторизация с использованием JWT-токенов.

## Технологии

- Python
- Django
- Django REST Framework
- SimpleJWT
- SQLite

## Запуск проекта

1. Активировать виртуальное окружение.
2. Установить зависимости из `requirements.txt`.
3. Выполнить миграции:

   `python manage.py migrate`

4. Запустить сервер:

   `python manage.py runserver`
